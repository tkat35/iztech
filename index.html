Motorlar: düz git, dön

2 DC motorL298N

Robot düz gitsin, yerinde 90° dönsün, yine düz gitsin.

  1. Tekerlekler havadayken kodu yükleyin. İki teker de ileri dönmeli; geri dönen motorun iki kablosunu sürücüde yer değiştirin.
  2. Robotu yere koyun, RESET'e basın; 3 saniye sonra hareket başlar.
  3. Robot bir yana kayıyorsa SAG_AYAR'ı değiştirin.
  4. Dönüş tam 90° olana kadar DONUS_MS'yi değiştirin.

Başarılı sayılır: robot üç denemede de aynı "L" şeklini çiziyor.

Bir adım öte: kare çizdirin. DONUS_MS değerini not edin; sonraki uygulamalarda lazım.

Kodu göster
İndir
// 1. MOTORLAR: duz git, 90 derece don, yine duz git
// Pinler sayfadaki ortak baglanti tablosuna goredir.
// Acildiktan 3 sn sonra bir kez calisir. Tekrar icin RESET dugmesine basin.

const byte SOL_PWM = 5, SOL_IN1 = 7, SOL_IN2 = 8;
const byte SAG_PWM = 6, SAG_IN1 = 9, SAG_IN2 = 10;

const int HIZ = 120;        // 0-255 arasi
const int SAG_AYAR = 0;     // Robot sola kayiyorsa eksi (-10), saga kayiyorsa arti (+10)
const int ILERI_MS = 1500;  // Ileri gitme suresi (ms)
const int DONUS_MS = 450;   // Tam 90 derece donene kadar bu sayiyi degistirin

void motor(byte pwm, byte in1, byte in2, int hiz) {
  hiz = constrain(hiz, -255, 255);
  digitalWrite(in1, hiz >= 0 ? HIGH : LOW);
  digitalWrite(in2, hiz >= 0 ? LOW : HIGH);
  analogWrite(pwm, abs(hiz));
}

void sur(int sol, int sag) {
  motor(SOL_PWM, SOL_IN1, SOL_IN2, sol);
  motor(SAG_PWM, SAG_IN1, SAG_IN2, sag);
}

void setup() {
  pinMode(SOL_PWM, OUTPUT); pinMode(SOL_IN1, OUTPUT); pinMode(SOL_IN2, OUTPUT);
  pinMode(SAG_PWM, OUTPUT); pinMode(SAG_IN1, OUTPUT); pinMode(SAG_IN2, OUTPUT);
  sur(0, 0);
  delay(3000);                                  // Robotu yere koymak icin zaman

  sur(HIZ, HIZ + SAG_AYAR);  delay(ILERI_MS);   // Ileri
  sur(0, 0);                 delay(500);
  sur(HIZ, -HIZ);            delay(DONUS_MS);   // Yerinde saga don
  sur(0, 0);                 delay(500);
  sur(HIZ, HIZ + SAG_AYAR);  delay(ILERI_MS);   // Yine ileri
  sur(0, 0);
}

void loop() {
  // Bos: hareket bir kez yapildi.
}

Çizgi sensörü: siyah mı beyaz mı?

4'lü çizgi sensörü

Dört göz de siyahı ve beyazı doğru ayırsın.

  1. Kodu yükleyin, Seri Monitör'ü açın (9600).
  2. Sensör beyaz zemindeyken dört göz de . göstermeli.
  3. Siyah bandın üstünde # göstermeli. Tersiyse SIYAH_LOW'u false yapın.
  4. Yanlış okuyan gözün vidasını (trimpot) küçük tornavidayla azar azar çevirin.

Başarılı sayılır: bandı soldan sağa geçirince yazı "solda → ortada → sağda" diye değişiyor.

Bir adım öte: sensörü yerden 0,5 cm, 1 cm, 1,5 cm yukarıda deneyin. Hangi yükseklik en iyi okuyor?

Kodu göster
İndir
// 2. CIZGI SENSORU: dort gozu oku, cizginin nerede oldugunu yaz
// OUT1-OUT4 soldan saga A0-A3. Seri Monitor: 9600 baud.

const byte CIZGI[4] = {A0, A1, A2, A3};
const bool SIYAH_LOW = true;  // Siyahta 0 okunuyorsa true, 1 okunuyorsa false yapin

bool cizgiVar(byte pin) {
  int d = digitalRead(pin);
  return SIYAH_LOW ? d == LOW : d == HIGH;
}

void setup() {
  Serial.begin(9600);
  for (byte i = 0; i < 4; i++) pinMode(CIZGI[i], INPUT);
}

void loop() {
  bool s[4];
  for (byte i = 0; i < 4; i++) {
    s[i] = cizgiVar(CIZGI[i]);
    Serial.print(s[i] ? "# " : ". ");   // # = siyah, . = beyaz
  }

  int sol = s[0] + s[1];
  int sag = s[2] + s[3];
  Serial.print("  -> ");
  if (sol + sag == 0)      Serial.println("cizgi yok");
  else if (sol + sag == 4) Serial.println("genis bant ya da kavsak");
  else if (sol > sag)      Serial.println("cizgi solda");
  else if (sag > sol)      Serial.println("cizgi sagda");
  else                     Serial.println("cizgi ortada");

  delay(150);
}

Mesafe sensörü: cetvelle yarış

HC-SR04 / HY-SRF05

Sensörün ölçtüğü mesafe cetveldekiyle uyuşuyor mu?

  1. Kodu yükleyin, Seri Monitör'ü açın.
  2. Sensörün önüne bir kitap koyun. 10, 20 ve 30 cm'de ölçümü cetvelle karşılaştırıp deftere yazın.
  3. Kalem, kumaş ve eğik tutulmuş bir kitapla deneyin.

Başarılı sayılır: 10–30 cm arasında fark 2 cm'den az.

Bir adım öte: hangi cisimlerde "ölçüm yok" çıktı? Ses dalgasına ne olmuş olabilir?

Kodu göster
İndir
// 3. MESAFE SENSORU (HC-SR04 / HY-SRF05): olc, ortalamasini al, cubuk ciz
// TRIG -> 11, ECHO -> 12. Seri Monitor: 9600 baud.

const byte TRIG = 11, ECHO = 12;

long olc() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long sure = pulseIn(ECHO, HIGH, 25000);  // En fazla 25 ms bekle
  return sure == 0 ? 0 : sure / 58;                 // 0 = olcum yok
}

// 5 olcumun ortalamasi. Olcum yoksa (0) ortalamaya katilmaz.
long mesafeCm() {
  long toplam = 0;
  int n = 0;
  for (int i = 0; i < 5; i++) {
    long cm = olc();
    if (cm > 0) { toplam += cm; n++; }
    delay(10);
  }
  return n > 0 ? toplam / n : 0;
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  long cm = mesafeCm();
  if (cm == 0) {
    Serial.println("olcum yok (cok uzak ya da egik yuzey)");
  } else {
    Serial.print(cm);
    Serial.print(" cm  ");
    long cubuk = cm > 60 ? 30 : cm / 2;   // Her = isareti 2 cm
    for (long i = 0; i < cubuk; i++) Serial.print('=');
    Serial.println('|');
  }
  delay(200);
}

Servo: açık ve kapalı açıyı bul

ServoK'Nex kol

Kolun zorlanmadan açıldığı ve kapandığı açıları bulun.

  1. Servo kolunu takmadan kodu yükleyin; Seri Monitör'e 90 yazıp Enter'a basın.
  2. Kolu 90°'de düz duracak şekilde takın.
  3. 10'ar derece deneyerek açık ve kapalı açıları bulun.
  4. Servo vızıldıyor ya da zorlanıyorsa açıyı 5° geri alın.

Başarılı sayılır: kol iki açı arasında takılmadan gidip geliyor, açılar deftere yazıldı.

Bir adım öte: K'Nex'ten bir kıskaç yapın. Bir kalemi düşürmeden tutabiliyor mu?

Kodu göster
İndir
// 4. SERVO: Seri Monitor'den aci yaz, servo o aciya gitsin
// Sinyal -> 3. Seri Monitor: 9600 baud, satir sonu "Yeni satir".

#include <Servo.h>

Servo kol;
const byte SERVO_PIN = 3;
const int EN_AZ = 10, EN_COK = 170;   // Guvenli sinirlar; mekanizmaya gore daraltin

void setup() {
  Serial.begin(9600);
  Serial.setTimeout(50);
  kol.attach(SERVO_PIN);
  kol.write(90);
  Serial.println("Bir aci yazip Enter'a basin (10-170):");
}

void loop() {
  if (Serial.available()) {
    int aci = Serial.parseInt();
    while (Serial.available()) Serial.read();   // Satir sonunu temizle

    if (aci >= EN_AZ && aci <= EN_COK) {
      kol.write(aci);
      Serial.print("Servo: ");
      Serial.println(aci);
    } else {
      Serial.println("10 ile 170 arasinda bir sayi yazin.");
    }
  }
}

Elimi takip et

MesafeMotor

Robot elinize 15 cm uzakta dursun; uzaklaşınca gelsin, yaklaşınca geri kaçsın.

  1. Mesafe sensörünü robotun önüne, yere paralel takın.
  2. Yere koyup kodu çalıştırın, elinizi önüne tutun.
  3. Robot yerinde ileri geri titriyorsa TOLERANS'ı artırın.

Başarılı sayılır: elinizi yavaşça çekince robot peşinizden geliyor. Masada değil, yerde deneyin.

Bir adım öte: el uzaktaysa hızlı, yakındaysa yavaş gitsin.

Kodu göster
İndir
// 5. MESAFE + MOTOR: elimi takip et
// Robot onundeki ele ya da kutuya 15 cm uzaklikta durmaya calisir:
// uzaklasirsan gelir, yaklasirsan geri kacar.

const byte SOL_PWM = 5, SOL_IN1 = 7, SOL_IN2 = 8;
const byte SAG_PWM = 6, SAG_IN1 = 9, SAG_IN2 = 10;
const byte TRIG = 11, ECHO = 12;

const int HIZ = 90;
const int HEDEF_CM = 15;
const int TOLERANS = 3;     // 12-18 cm arasi "tamam" sayilir
const int MENZIL_CM = 60;   // Bundan uzaksa kimse yok, bekle

void motor(byte pwm, byte in1, byte in2, int hiz) {
  hiz = constrain(hiz, -255, 255);
  digitalWrite(in1, hiz >= 0 ? HIGH : LOW);
  digitalWrite(in2, hiz >= 0 ? LOW : HIGH);
  analogWrite(pwm, abs(hiz));
}
void sur(int sol, int sag) {
  motor(SOL_PWM, SOL_IN1, SOL_IN2, sol);
  motor(SAG_PWM, SAG_IN1, SAG_IN2, sag);
}

long olc() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long sure = pulseIn(ECHO, HIGH, 25000);
  return sure == 0 ? 0 : sure / 58;
}

void setup() {
  pinMode(SOL_PWM, OUTPUT); pinMode(SOL_IN1, OUTPUT); pinMode(SOL_IN2, OUTPUT);
  pinMode(SAG_PWM, OUTPUT); pinMode(SAG_IN1, OUTPUT); pinMode(SAG_IN2, OUTPUT);
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  sur(0, 0);
  delay(2000);
}

void loop() {
  long cm = olc();

  if (cm == 0 || cm > MENZIL_CM)        sur(0, 0);       // Kimse yok: bekle
  else if (cm > HEDEF_CM + TOLERANS)    sur(HIZ, HIZ);   // Uzak: yaklas
  else if (cm < HEDEF_CM - TOLERANS)    sur(-HIZ, -HIZ); // Yakin: geri kac
  else                                  sur(0, 0);       // Tam yerinde: dur

  delay(30);
}

  1. 2 cm'lik siyah bantla bir oval ve bir S viraj yapın.

const bool SIYAH_LOW = true;

const int HIZ = 100;      // Duz giderken
const int YAVAS = 45;     // Donus icindeki teker
const int ARA = 60;       // Cizgi kayipken arama hizi

int sonYon = 0;           // -1 sol, +1 sag, 0 bilinmiyor

void motor(byte pwm, byte in1, byte in2, int hiz) {
  hiz = constrain(hiz, -255, 255);
  digitalWrite(in1, hiz >= 0 ? HIGH : LOW);
  digitalWrite(in2, hiz >= 0 ? LOW : HIGH);
  analogWrite(pwm, abs(hiz));
}

  motor(SOL_PWM, SOL_IN1, SOL_IN2, sol);
  motor(SAG_PWM, SAG_IN1, SAG_IN2, sag);
}

  int d = digitalRead(pin);
  return SIYAH_LOW ? d == LOW : d == HIGH;
}

void setup() {
  pinMode(SOL_PWM, OUTPUT); pinMode(SOL_IN1, OUTPUT); pinMode(SOL_IN2, OUTPUT);
  pinMode(SAG_PWM, OUTPUT); pinMode(SAG_IN1, OUTPUT); pinMode(SAG_IN2, OUTPUT);
  for (byte i = 0; i < 4; i++) pinMode(CIZGI[i], INPUT);

  delay(2000);

  else {                                                    // Cizgi kayip
    if (sonYon < 0)      sur(-ARA, ARA);
    else if (sonYon > 0) sur(ARA, -ARA);
    else                 sur(0, 0);
  }
}

Radar

ServoMesafe

Robot beş yöne baksın, en açık yönü söylesin.

  1. Mesafe sensörünü servonun koluna takın.
  2. Kodu yükleyin, Seri Monitör'ü açın.

Kodu göster
İndir
// 8. SERVO + MESAFE: radar
// Servo uzerindeki mesafe sensoru 5 yone bakar, en acik yonu yazar.
// Motorlar calismaz; robot masada durabilir. Seri Monitor: 9600 baud.

#include <Servo.h>

const byte TRIG = 11, ECHO = 12;
const byte SERVO_PIN = 3;
const int ACILAR[5] = {30, 60, 90, 120, 150};   // 30 = sag, 150 = sol (montaja gore degisebilir)

Servo kafa;

long olc() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long sure = pulseIn(ECHO, HIGH, 25000);
  return sure == 0 ? 0 : sure / 58;
}

long mesafeCm() {
  long toplam = 0;
  int n = 0;
  for (int i = 0; i < 3; i++) {
    long cm = olc();
    if (cm > 0) { toplam += cm; n++; }
    delay(10);
  }
  return n > 0 ? toplam / n : 0;
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  kafa.attach(SERVO_PIN);
  kafa.write(90);
  delay(500);
}

void loop() {
  int enIyiAci = 90;
  long enUzak = 0;

  for (int i = 0; i < 5; i++) {
    kafa.write(ACILAR[i]);
    delay(300);                    // Servo yerine otursun, sonra olc
    long cm = mesafeCm();
    Serial.print(ACILAR[i]);
    Serial.print(" derece: ");
    if (cm == 0) Serial.println("olcum yok");
    else { Serial.print(cm); Serial.println(" cm"); }
    if (cm > enUzak) { enUzak = cm; enIyiAci = ACILAR[i]; }
  }

  Serial.print("En acik yon: ");
  Serial.print(enIyiAci);
  if (enIyiAci < 90)      Serial.println(" (sag)");
  else if (enIyiAci > 90) Serial.println(" (sol)");

Engelden kaç

MotorServoMesafe

Robot engellere çarpmadan dolaşsın.

  1. Sensör servonun üstünde kalsın (radardaki gibi).
  2. DONUS_MS'ye kendi değerinizi yazın.
  3. Kutularla küçük bir engel alanı kurup robotu bırakın.

Başarılı sayılır: robot 2 dakika boyunca hiçbir engele çarpmıyor.

Bir adım öte: sol da sağ da kapalıysa robot geri dönsün (180°).

Kodu göster
İndir
// 9. MOTOR + SERVO + MESAFE: engelden kacan robot
// Ileri gider; onde engel varsa durur, saga ve sola bakar, acik tarafa doner.

#include <Servo.h>

const byte SOL_PWM = 5, SOL_IN1 = 7, SOL_IN2 = 8;
const byte SAG_PWM = 6, SAG_IN1 = 9, SAG_IN2 = 10;
const byte TRIG = 11, ECHO = 12;
const byte SERVO_PIN = 3;

const int HIZ = 90;
const int ENGEL_CM = 20;
const int DONUS_MS = 450;           // 90 derece suresi (1. uygulama)
const int SOL_ACI = 150, SAG_ACI = 30;

Servo kafa;

void motor(byte pwm, byte in1, byte in2, int hiz) {
  hiz = constrain(hiz, -255, 255);
  digitalWrite(in1, hiz >= 0 ? HIGH : LOW);
  digitalWrite(in2, hiz >= 0 ? LOW : HIGH);
  analogWrite(pwm, abs(hiz));
}
void sur(int sol, int sag) {
  motor(SOL_PWM, SOL_IN1, SOL_IN2, sol);
  motor(SAG_PWM, SAG_IN1, SAG_IN2, sag);
}

long olc() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long sure = pulseIn(ECHO, HIGH, 25000);
  return sure == 0 ? 0 : sure / 58;
}

long bak(int aci) {                 // Servoyu cevir, olc
  kafa.write(aci);
  delay(350);
  long cm = olc();
  return cm == 0 ? 400 : cm;        // Olcum yoksa "acik" kabul et
}

void setup() {
  pinMode(SOL_PWM, OUTPUT); pinMode(SOL_IN1, OUTPUT); pinMode(SOL_IN2, OUTPUT);
  pinMode(SAG_PWM, OUTPUT); pinMode(SAG_IN1, OUTPUT); pinMode(SAG_IN2, OUTPUT);
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  kafa.attach(SERVO_PIN);
  kafa.write(90);
  sur(0, 0);
  delay(2000);
}

void loop() {
  long on = olc();
  if (on == 0 || on > ENGEL_CM) {   // Yol acik
    sur(HIZ, HIZ);
    delay(30);
    return;
  }

  sur(0, 0);       delay(150);
  sur(-HIZ, -HIZ); delay(250);      // Biraz geri
  sur(0, 0);

  long sol = bak(SOL_ACI);
  long sag = bak(SAG_ACI);
  kafa.write(90);

  if (sol >= sag) sur(-HIZ, HIZ);   // Sol daha acik: sola don
  else            sur(HIZ, -HIZ);   // Sag daha acik: saga don
  delay(DONUS_MS);
  sur(0, 0);
  delay(200);
}

// TYY BASLANGIC TASLAGI - Odemis BILSEM
// Pinler ORNEKTIR. Kendi baglantiniza gore degistirin.
#include <Servo.h>

// ---- PINLER ----
const byte SOL_PWM = 5, SOL_IN1 = 7, SOL_IN2 = 8;   // L298N sol motor
const byte SAG_PWM = 6, SAG_IN1 = 9, SAG_IN2 = 10;  // L298N sag motor
const byte TRIG = 11, ECHO = 12;                    // HC-SR04
const byte SERVO_PIN = 3;                           // Servo sinyal
const byte CIZGI[4] = {A0, A1, A2, A3};             // 4'lu sensor, soldan saga

// ---- AYARLAR (testte bulun) ----
const bool SIYAH_LOW = true;   // Siyahta sensor LOW veriyorsa true
const int  HIZ = 90;           // Temel hiz (0-255)
const int  YAKIN_CM = 10;      // Nesneye bu kadar yaklasinca dur
const int  SERVO_ACIK = 110, SERVO_KAPALI = 55;

Servo kol;

// ---- GOREV ADIMLARI: temaya gore burayi degistirin ----
enum Adim { BASLA, CIZGI_TAKIP, YAKLAS, AL, DONUS, BIRAK, BITTI };
Adim adim = BASLA;
unsigned long adimBaslangic = 0;

void adimaGec(Adim yeni) {
  adim = yeni;
  adimBaslangic = millis();
  Serial.print("Adim: ");
  Serial.println(yeni);
}
unsigned long adimSuresi() { return millis() - adimBaslangic; }

// ---- MOTOR ----
void motor(byte pwm, byte in1, byte in2, int hiz) {
  hiz = constrain(hiz, -255, 255);
  digitalWrite(in1, hiz >= 0 ? HIGH : LOW);
  digitalWrite(in2, hiz >= 0 ? LOW : HIGH);
  analogWrite(pwm, abs(hiz));
}
void sur(int sol, int sag) {
  motor(SOL_PWM, SOL_IN1, SOL_IN2, sol);
  motor(SAG_PWM, SAG_IN1, SAG_IN2, sag);
}
void dur() { sur(0, 0); }

// ---- MESAFE ----
long mesafeCm() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long sure = pulseIn(ECHO, HIGH, 25000);
  return sure == 0 ? 0 : sure / 58;   // 0 = olcum yok
}

// ---- CIZGI ----
bool s[4];
int sonHata = 0;
bool cizgiVar(byte pin) {
  int d = digitalRead(pin);
  return SIYAH_LOW ? d == LOW : d == HIGH;
}
int sensorSay() {   // Kac goz cizgiyi goruyor? (0-4)
  int n = 0;
  for (byte i = 0; i < 4; i++) { s[i] = cizgiVar(CIZGI[i]); if (s[i]) n++; }
  return n;
}
void cizgiTakip(int hiz) {   // P kontrol, agirliklar -3 -1 +1 +3
  const int AGIRLIK[4] = {-3, -1, 1, 3};
  long toplam = 0; int n = 0;
  for (byte i = 0; i < 4; i++) if (s[i]) { toplam += AGIRLIK[i]; n++; }
  int hata = (n > 0) ? toplam / n : sonHata;
  sonHata = hata;
  int duzeltme = hata * 25;
  sur(hiz + duzeltme, hiz - duzeltme);
}

void setup() {
  Serial.begin(9600);
  pinMode(SOL_PWM, OUTPUT); pinMode(SOL_IN1, OUTPUT); pinMode(SOL_IN2, OUTPUT);
  pinMode(SAG_PWM, OUTPUT); pinMode(SAG_IN1, OUTPUT); pinMode(SAG_IN2, OUTPUT);
  pinMode(TRIG, OUTPUT); pinMode(ECHO, INPUT);
  for (byte i = 0; i < 4; i++) pinMode(CIZGI[i], INPUT);
  kol.attach(SERVO_PIN);
  kol.write(SERVO_ACIK);
  dur();
  adimaGec(BASLA);
}

void loop() {
  int gorenSensor = sensorSay();

  switch (adim) {
    case BASLA:                       // 2 sn bekle, sonra yola cik
      if (adimSuresi() > 2000) adimaGec(CIZGI_TAKIP);
      break;

    case CIZGI_TAKIP: {               // Cizgiyi izle, onde nesne varsa yaklas
      cizgiTakip(HIZ);
      long cm = mesafeCm();
      if (cm > 0 && cm < 25) adimaGec(YAKLAS);
      break;
    }

    case YAKLAS: {                    // Yavasca nesneye yaklas
      long cm = mesafeCm();
      if (cm == 0) dur();             // Olcum yoksa ilerleme
      else if (cm > YAKIN_CM) sur(60, 60);
      else { dur(); adimaGec(AL); }
      break;
    }

    case AL:                          // Kolu kapat, biraz geri cekil
      kol.write(SERVO_KAPALI);
      if (adimSuresi() > 600) sur(-60, -60);
      if (adimSuresi() > 1000) { dur(); adimaGec(DONUS); }
      break;

    case DONUS:                       // Yerinde don (sureyi olcun)
      sur(80, -80);
      if (adimSuresi() > 700) { dur(); adimaGec(BIRAK); }
      break;

    case BIRAK:                       // Hedef: 4 sensor de siyah (genis bant)
      if (gorenSensor == 4) {
        dur();
        kol.write(SERVO_ACIK);
        adimaGec(BITTI);
      } else {
        cizgiTakip(70);
      }
      break;

    case BITTI:
      dur();
      break;
  }
  delay(10);
}

Motor testi. Tekerlekler havadayken çalıştırın: ileri, dur, geri.

// L298N icin ornek Uno pinleri
const byte SOL_PWM = 5, SOL_IN1 = 7, SOL_IN2 = 8;
const byte SAG_PWM = 6, SAG_IN1 = 9, SAG_IN2 = 10;

void motor(byte pwm, byte in1, byte in2, int hiz) {
  hiz = constrain(hiz, -255, 255);
  digitalWrite(in1, hiz >= 0 ? HIGH : LOW);
  digitalWrite(in2, hiz >= 0 ? LOW : HIGH);
  analogWrite(pwm, abs(hiz));
}
void sur(int sol, int sag) {
  motor(SOL_PWM, SOL_IN1, SOL_IN2, sol);
  motor(SAG_PWM, SAG_IN1, SAG_IN2, sag);
}

void setup() {
  pinMode(SOL_PWM, OUTPUT); pinMode(SOL_IN1, OUTPUT); pinMode(SOL_IN2, OUTPUT);
  pinMode(SAG_PWM, OUTPUT); pinMode(SAG_IN1, OUTPUT); pinMode(SAG_IN2, OUTPUT);
}

void loop() {
  sur(90, 90);   delay(1000);  // Ileri. Bir teker geri donuyorsa kablolarini degistir.
  sur(0, 0);     delay(700);   // Dur
  sur(-80, -80); delay(700);   // Geri
  sur(0, 0);     delay(1500);
}

Çizgi sensörü testi. Seri Monitör'de dört gözün değerini görün; siyahta 0 mı 1 mi?

// 4'lu sensorun OUT1-OUT4 pinleri soldan saga A0-A3'e
const byte CIZGI[4] = {A0, A1, A2, A3};

void setup() {
  Serial.begin(9600);
  for (byte i = 0; i < 4; i++) pinMode(CIZGI[i], INPUT);
}

void loop() {
  for (byte i = 0; i < 4; i++) {
    Serial.print(digitalRead(CIZGI[i]));
    Serial.print(' ');
  }
  Serial.println();
  delay(100);
}
// Siyah cizgide 0 goruyorsan taslakta SIYAH_LOW = true kalsin.
// Kartin uzerindeki vidalarla (trimpot) hassasiyeti ayarla.

Mesafe testi. HC-SR04 ile santimetre ölçün. 0 gelirse ölçüm yok demektir.

const byte TRIG = 11, ECHO = 12;

long mesafeCm() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long sure = pulseIn(ECHO, HIGH, 25000); // En fazla 25 ms bekle
  return sure == 0 ? 0 : sure / 58;
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  long cm = mesafeCm();
  if (cm == 0) Serial.println("Olcum yok");
  else { Serial.print(cm); Serial.println(" cm"); }
  delay(150);
}

Servo testi. Kolun güvenli açık ve kapalı açısını bulun.

#include <Servo.h>
Servo kol;
const byte SERVO_PIN = 3;

void setup() {
  kol.attach(SERVO_PIN);
}

void loop() {
  kol.write(55);  delay(800);   // Kapali denemesi
  kol.write(90);  delay(800);   // Orta
  kol.write(110); delay(800);   // Acik denemesi
}
// Servo zorlaniyor/vizildiyorsa aciyi daralt.
// Bulduğun degerleri taslaktaki SERVO_ACIK ve SERVO_KAPALI'ya yaz.
Pinler örnektir. Yarışmada verilecek elektronik parçaların modeli kurallarda yazmıyor. Farklı bir sürücü ya da sensör çıkarsa yalnız ilgili modülü değiştirin.
Motoru Arduino'nun 5V pininden beslemeyin. Motorlar sürücüden ve pilden beslenir; tüm GND'ler ortak olmalı.
Her çalışan sürümü kaydedin. Örnek: tyy_v3_kiskac_calisiyor.ino. Bir şey bozulursa bir önceki sürüme dönersiniz.

Yarışma günü: 24 saat planı

Saatler yarışmanın başlangıcından itibaren sayılır. Tema provasındaki sayaç bu planın kısaltılmış hâlidir.

  1. 0 – 1. saat · Anla

    Temayı ve kuralları dinleyin, örnek parkuru izleyin. Sorularınızı o an sorun. Gelen malzemeyi sayıp listeleyin.

  2. 1 – 2. saat · Planla

    Herkes bir fikir söylesin, üç seçenekten birini seçin. Robotu kâğıda çizin: gövde, sensörlerin yeri, mekanizma.

  3. 2 – 8. saat · Yap

    Mekanik gövdeyi, elektronik kabloları, yazılım taslağı temaya uyarlamayı aynı anda yapar. 8. saatte robot yürümeli.

  4. 8 – 10. saat · İlk sürüş

    Motor yönleri, sensör eşikleri, servo açıları. Her denemeyi test defterine yazın.

  5. 10 – 14. saat · Dinlenme vardiyası

    İkişer kişi dönüşümlü dinlenir. Yorgun ekip hata yapar; vardiyayı planlayın.

  6. 14 – 20. saat · Görevi çöz

    Görevi baştan sona deneyin, en çok kaybettiren tek sorunu düzeltin, tekrar deneyin.

  7. 20 – 22. saat · Dondur

    Yeni özellik yok. Çalışan kodu kaydedin, kabloları bağlarla toplayın, yedek alın.

  8. 22 – 24. saat · Sun ve taşı

    Sunum provası yapın. Robotu pist alanına taşıyın: bitmeyen robot değerlendirilmez ama pist alanına taşınmak zorunda.
